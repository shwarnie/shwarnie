## 💭 A Few Things I've Learned

```text
1. Google is not a last resort. It is part of the workflow.

2. "It works on my machine" is not a solution.

3. Read the error message.
   Seriously. Read it.

4. Sometimes the problem is not complicated.
   You just forgot one character.

5. Breaking things is sometimes the fastest way to understand them.

6. You don't need to know everything before you start building.
```
